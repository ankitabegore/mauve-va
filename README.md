# mauve-va

An AI-powered personal voice assistant built with Python, integrating speech-to-text, natural language processing, and text-to-speech technologies. MAUVE provides a smooth conversational experience with real-time interaction and an intuitive interface.

Features
- Speech Recognition: Converts live voice input to text using Deepgram API.
- Intelligent Responses: Processes user queries via OpenAI GPT API.
- Voice Output: Delivers natural speech using ElevenLabs API.
- Interactive UI: Built with Taipy for a clean, responsive interface and Pygame for real-time audio playback.
- Cross-Platform Support: Operates via both web and terminal interfaces.
